### Changed

- Computer use on macOS: when an app receives an accessibility request but never answers it (for example because the press opened a modal dialog), pressing or performing an action, setting a value and focusing an element now report `AxUnconfirmed` ("it may already have taken effect, observe before retrying") instead of `AxFailed`, so the agent no longer retries an action that may have landed. Refused requests still report `AxFailed`. ([#11506](https://github.com/code-yeongyu/oh-my-openagent/pull/11506), part of [#11461](https://github.com/code-yeongyu/oh-my-openagent/issues/11461))
